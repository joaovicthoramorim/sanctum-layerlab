# Sanctum — website concept by LAYER LAB

Private prototype for wearesanctum.com.

- `public/` — the built website (this is what Netlify publishes).
- `src/` — source: `data.mjs` (content), `build.mjs` (page generator), `styles.css`, `app.js`.

Every push to `main` publishes automatically on Netlify.
